# בוט קבלות לכלות 💍 (טלגרם / אינסטגרם)

שולחים לבוט בטלגרם הודעה אחת, למשל:

```
דנה כהן 1500 ביט 052-1234567
```

והבוט:
1. **מפיק קבלה**: ב-Hyp (EZcount) כקבלה רשמית, או כתמונת PNG בעברית אם Hyp לא מחובר.
2. **שולח לכם את הקבלה** בצ'אט (PDF או תמונה).
3. **מוסיף כפתור "📲 שליחה לכלה בוואטסאפ"**. לחיצה עליו פותחת את וואטסאפ עם הודעה מוכנה לכלה, כולל קישור לקבלה. נשאר רק ללחוץ "שליחה".

אפשר להפעיל את אותו בוט גם בדיירקט של אינסטגרם (ראו "אינסטגרם" בהמשך), אבל טלגרם פשוט יותר להגדרה.

## מה אפשר לכתוב בהודעה

| מה | דוגמאות | חובה? |
|---|---|---|
| שם הכלה | `דנה כהן`, `קבלה ללאה אברהם` | ✅ |
| סכום | `1500`, `2,300 ש"ח`, `850.50₪` | ✅ |
| צורת תשלום | ביט, פייבוקס, מזומן, העברה / העברה בנקאית, אשראי, צ'ק, Apple Pay, Google Pay, PayPal | ✅ |
| טלפון של הכלה | `052-1234567`, `+972521234567` | לא. עם טלפון וואטסאפ נפתח ישר בצ'אט שלה, ובלי טלפון בוחרים איש קשר |
| סוג התשלום | מקדמה, יתרה, תשלום מלא | לא. מופיע בשורה "עבור" |

הסדר לא משנה. דוגמאות:

```
נועה לוי, 2,300 ש"ח, העברה בנקאית
שירה 1200₪ אשראי מקדמה
קבלה ללאה אברהם 800 במזומן 052-1234567
```

ההודעה `עזרה` מחזירה הסבר.

## ניסיון מקומי (בלי טלגרם)

```bash
pip install -r requirements-dev.txt
sudo apt-get install fonts-noto-core   # פעם אחת, לבניית הגופן העברי של הקבלה
python -m app.build_fonts
cp .env.example .env        # ממלאים את פרטי העסק
python -m app.cli "דנה כהן 1500 ביט 052-1234567"
```

הפקודה מדפיסה את קישור הוואטסאפ ואת הנתיב לתמונת הקבלה בתיקייה `data/receipts/`.
להרצת הבדיקות: `pytest`.

## התקנה מלאה

### 1. העלאת השרת לאינטרנט
הבוט צריך כתובת `https` ציבורית. הדרך הפשוטה היא [Render](https://render.com):
- מחברים את הריפו הזה (New → Blueprint). הקובץ `render.yaml` כבר מגדיר שרת Docker בתוכנית **החינמית**.
- בתוכנית החינמית השרת "נרדם" אחרי כ-15 דקות בלי שימוש, ולכן ההודעה הראשונה אחרי הפסקה נענית אחרי כחצי דקה.
- ממלאים את משתני הסביבה לפי `.env.example`. ב-`PUBLIC_BASE_URL` שמים את הכתובת ש-Render נותן, למשל `https://receipt-bot-xxxx.onrender.com`.

אפשר גם בכל שרת אחר שמריץ Docker:
`docker build -t receipt-bot . && docker run -p 8000:8000 -v $PWD/data:/data --env-file .env receipt-bot`

> עם Hyp הקבלות נשמרות ב-Hyp, ולכן לא צריך דיסק קבוע. **בלי Hyp** (קבלות כתמונה מקומית) צריך דיסק קבוע, אחרת הקבלות ומספור הקבלות יימחקו בכל עדכון של השרת. במקרה כזה משנים ב-`render.yaml` ל-`plan: starter` ומוסיפים דיסק שמחובר ל-`/data`.

### 2. יצירת בוט בטלגרם
1. בטלגרם פותחים צ'אט עם [@BotFather](https://t.me/BotFather) ושולחים `/newbot`.
2. בוחרים שם לבוט ושם משתמש שמסתיים ב-`bot`, למשל `my_receipts_bot`.
3. BotFather שולח **טוקן**. שמים אותו בשרת ב-`TELEGRAM_BOT_TOKEN`.
4. `TELEGRAM_WEBHOOK_SECRET` לא חובה. אם משאירים אותו ריק, הבוט מייצר סוד קבוע מתוך הטוקן.

כשהשרת עולה, הוא רושם את עצמו בטלגרם לבד (webhook). לכן `PUBLIC_BASE_URL` חייב להיות מוגדר לכתובת ה-`https` של השרת.

### 3. נעילת הבוט רק לכם
1. פותחים את הבוט בטלגרם ושולחים `/start`.
2. כל עוד `TELEGRAM_ALLOWED_USER_IDS` ריק, הבוט עונה עם ה-ID שלכם.
3. מעתיקים את ה-ID ל-`TELEGRAM_ALLOWED_USER_IDS` ושומרים. מעכשיו רק אתם יכולים להפיק קבלות, ואחרים לא מקבלים תשובה.

## חיבור ל-Hyp (EZcount): קבלות רשמיות

אם יש לכם חשבון ב-Hyp, הבוט יכול להפיק את הקבלה **ישירות במערכת שלכם**. ככה היא ממוספרת ונשמרת שם כמסמך רשמי, ובמקום תמונה הכלה מקבלת קישור ל-PDF של Hyp.

1. ב-Hyp נכנסים ל**התממשקויות** → **מפתח API**, ומעתיקים את המפתח.
2. מגדירים בשרת:
   - `HYP_API_KEY`: המפתח.
   - `HYP_DEVELOPER_EMAIL`: כתובת המייל שלכם.
   - `HYP_DOC_TYPE`: `400` לקבלה, או `320` לחשבונית מס/קבלה אם אתם עוסק מורשה.
3. **כדאי לבדוק קודם בסביבת הדמו:** `HYP_API_BASE=https://demo.ezcount.co.il` עם מפתח של סביבת הדמו. אחרי שהכול עובד, מחליפים ל-`https://api.ezcount.co.il`.

**המפתח סודי.** שמים אותו רק במשתני הסביבה של השרת, ולא בקוד, לא בגיטהאב ולא בצילומי מסך.

### איך צורת התשלום עוברת ל-Hyp

| בהודעה | ב-Hyp |
|---|---|
| מזומן | 1 (מזומן) |
| צ'ק | 2 (המחאה) |
| אשראי | 3 (כרטיס אשראי) |
| העברה / העברה בנקאית | 4 (העברה בנקאית) |
| ביט, פייבוקס, PayPal, Apple Pay, Google Pay | 9 (אחר), עם שם האמצעי בהערה |

כל הודעה נשלחת עם `transaction_id` (מזהה ההודעה בטלגרם או באינסטגרם). לכן אם Meta שולחת את אותה הודעה שוב, לא אמורה להיווצר קבלה כפולה.

## אינסטגרם (לא חובה)
אותו בוט יכול לעבוד גם בדיירקט של אינסטגרם, בנוסף לטלגרם או במקומו.

### אפליקציה ב-Meta
1. החשבון באינסטגרם צריך להיות **חשבון מקצועי** (עסקי או יוצר תוכן).
2. נכנסים ל-[developers.facebook.com](https://developers.facebook.com), יוצרים אפליקציה (Business) ומוסיפים את המוצר **Instagram** (API setup with Instagram login).
3. מחברים את חשבון האינסטגרם ומפיקים **Access Token**. שמים אותו ב-`IG_ACCESS_TOKEN`.
4. מעתיקים את **App Secret** (App settings → Basic) אל `META_APP_SECRET`.
5. בהגדרת ה-Webhooks:
   - Callback URL: `https://<הכתובת שלכם>/webhook`
   - Verify token: המחרוזת ששמתם ב-`IG_VERIFY_TOKEN`
   - נרשמים לשדה **messages**.
6. בהגדרות אינסטגרם באפליקציה בטלפון: הגדרות → הודעות → **אפשר גישה להודעות** (Connected tools / Allow access to messages).

> מאחר שהבוט משמש רק אתכם, האפליקציה יכולה להישאר במצב Development. אין צורך לעבור App Review, כל עוד מי ששולח לבוט מוגדר כ-Tester/Admin באפליקציה.

### שליחה לבוט מהחשבון הפרטי
הבוט הוא חשבון העסק, ואתם כותבים לו **מחשבון אחר**, למשל החשבון הפרטי שלכם (שגם הוא צריך להיות Tester באפליקציה).
1. שולחים לבוט הודעה כלשהי.
2. כל עוד `ALLOWED_SENDER_IDS` ריק, הבוט עונה עם ה-ID שלכם.
3. מעתיקים את ה-ID למשתנה `ALLOWED_SENDER_IDS` ומפעילים מחדש. מעכשיו רק אתם יכולים להפיק קבלות, והודעות מאנשים אחרים מתעלמות.

## התאמה אישית
- **הודעת הוואטסאפ לכלה**: מגדירים את `WHATSAPP_TEMPLATE` (המשתנים הזמינים מפורטים ב-`.env.example`).
- **לוגו**: מגדירים ב-`LOGO_PATH` נתיב לקובץ PNG.
- **מספר הקבלה הראשון**: `RECEIPT_START_NUMBER`.
- **עיצוב הקבלה**: הקובץ `app/receipt.py` (צבעים, גדלים וטקסטים).

## מבנה הקוד
```
app/parser.py     ניתוח המשפט: שם, סכום, צורת תשלום, טלפון, מקדמה/יתרה
app/receipt.py    ציור הקבלה כתמונה
app/service.py    התהליך המלא: ניתוח, מספור, תמונה וקישור וואטסאפ
app/whatsapp.py   בניית קישור wa.me
app/hyp.py        הפקת קבלה רשמית ב-Hyp (EZcount)
app/telegram.py   שליחת הודעות, קבצים וכפתורים בטלגרם
app/instagram.py  שליחת הודעות דרך Instagram API ובדיקת חתימת Webhook
app/main.py       שרת FastAPI (‎/telegram/webhook‎, ‎/webhook‎ לאינסטגרם, ‎/r/<token>.png‎)
app/cli.py        הרצה מקומית מהטרמינל
```
