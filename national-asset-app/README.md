# נכס לאומי – אפליקציית התראה לאנדרואיד 🚨

כשמופעל "נכס לאומי" (תרגיל או אמת), האפליקציה:

1. **שולחת SMS** לכל רשימת התפוצה, מהסים של הטלפון שלכם (בלי עלות נוספת).
2. **מזהה מי השיב.** כל תשובה שמגיעה ממספר שברשימה מסמנת את האדם כ"נמצא", יחד עם התשובה והשעה.
3. **מתקשרת במקביל לכולם** (דרך Twilio). כשעונים, נאמר "נכס לאומי" בקול עברי והשיחה מתנתקת.
   האפליקציה בודקת שעונה **אדם**: תא קולי לא נחשב מענה. מי שלא ענה מקבל חיוג חוזר אוטומטי (ברירת מחדל: עד 3 ניסיונות, דקה ביניהם).
4. **מסך ראשי** שמראה בזמן אמת "נמצאו X מתוך Y". לכל אדם מופיעים מצב ה-SMS, מצב השיחה ואיך הוא נמצא. אפשר גם לסמן אדם ידנית.
5. **הפעלה מהודעה נכנסת.** כשמגיע SMS כמו `הופעל נכס לאומי תרגילי` או `הופעל נכס לאומי אמת`, קופצת התראה עם צלצול, ולחיצה אחת מפעילה (אפשר להגדיר גם הפעלה מיידית).
6. **דוח לשיתוף** (וואטסאפ, מייל וכו'): מי נמצא, איך ומתי, ומי לא.

---

## התקנה

1. בטלפון, פתחו את דף ה-Release בשם **national-asset-latest** בריפו (Releases ← `national-asset-latest`) והורידו את `NechesLeumi.apk`.
   לחלופין: Actions ← **National Asset APK** ← הריצה האחרונה ← Artifacts.
2. פתחו את הקובץ ואשרו "התקנה ממקורות לא ידועים". אם Play Protect מזהיר, בחרו "התקן בכל זאת".
3. בפתיחה הראשונה אשרו את ההרשאות: **SMS** (שליחה וקבלה) ו**התראות**.
4. באנדרואיד 13 ומעלה ייתכן שהרשאת ה-SMS תיחסם ("הגדרה מוגבלת"). במקרה כזה:
   הגדרות ← אפליקציות ← נכס לאומי ← ⋮ (למעלה) ← **"אפשר הגדרות מוגבלות"**, ואז אשרו את ההרשאה.

> כל בנייה חדשה מותקנת כעדכון מעל הקודמת, והרשימה וההגדרות נשמרות.

## הגדרת Twilio (בשביל השיחות)

1. נרשמים ב-[twilio.com](https://www.twilio.com) ומטעינים קרדיט. את המחיר לשיחה לנייד בישראל רואים במחירון של Twilio (Voice pricing ← Israel). כל שיחה נמשכת כ-10 שניות.
2. **Voice → Settings → Geo permissions**: מסמנים את **Israel**.
3. מספר יוצא: יש שתי אפשרויות.
   * **הכי פשוט:** Phone Numbers → **Verified Caller IDs** → מאמתים את הנייד שלכם. השיחות יוצגו מהמספר שלכם.
   * או קונים מספר ב-Twilio.
4. מעתיקים מדף הבית של הקונסולה את **Account SID** ואת **Auth Token**.
5. באפליקציה: ⚙️ הגדרות ← ממלאים SID, Token ומספר יוצא ← **בדיקת חיבור**, ואז **שיחת ניסיון** למספר שלכם.

## שימוש

* 👤 **רשימת תפוצה**: מוסיפים אנשים ידנית, מאנשי הקשר, או בייבוא של הרבה בבת אחת (שורה לכל אדם: `שם, מספר`).
* במסך הראשי לוחצים **תרגיל** או **אמת**, מאשרים, וזהו.
* במהלך האירוע:
  * לחיצה על אדם פותחת תפריט: סימון ידני, חיוג חוזר, SMS חוזר, או "התקשר בעצמי".
  * **חייג שוב**: חיוג חוזר לכל מי שעוד לא נמצא.
  * **שתף דוח**: שולח את הסיכום.
  * **סיום**: עוצר את השיחות הפעילות. הדוח נשאר עד "סגור אירוע".

## מתי אדם נחשב "נמצא"

| איך | מתי |
|---|---|
| ענה לשיחה | Twilio זיהה שענה אדם (לא תא קולי) |
| השיב בהודעה | הגיע SMS ממספר שברשימה אחרי תחילת האירוע |
| סומן ידנית | סימנתם בעצמכם |

## הגדרות שכדאי להכיר

* **נוסח ה-SMS** לתרגיל ולאמת: ניתן לעריכה.
* **מה נאמר בשיחה**: ברירת המחדל היא "נכס לאומי", ואפשר לכתוב למשל `נכס לאומי {mode}` כדי שייאמר גם "תרגיל" או "אמת".
* **זיהוי תא קולי**: מומלץ להשאיר דלוק. הוא מוסיף כמה שניות עד שההודעה מושמעת.
* **שולחים מורשים**: אם ממלאים, רק הודעות מהמספרים או מהשמות האלה יפעילו את ההתראה.

## הערות

* פרטי Twilio נשמרים מקומית בטלפון בלבד.
* ה-SMS נשלחים מהסים. בטלפון עם שני סימים נעשה שימוש בסים ברירת המחדל להודעות.
* האפליקציה לא מתאימה ל-Google Play (בגלל הרשאות ה-SMS) ומיועדת להתקנה ישירה.
